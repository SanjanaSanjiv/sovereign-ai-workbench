# Sovereign AI Workbench

Sovereign On-Premise Agentic AI Workbench using Open-Weight Multimodal LLMs for Confidential Industrial Work.

## Project Goal

A self-hosted AI workbench designed for confidential industrial environments where sensitive documents and knowledge must remain on-premises.

## Current Status

- Ollama installed
- Qwen3 4B running locally
- Git repository initialized
- Initial project structure created

## Planned Components

- Local multi-model management
- Automatic model routing
- Agentic task execution
- Local RAG / knowledge base
- Document and image understanding
- OCR and vision processing
- Sandboxed code execution
- Word / Excel / PowerPoint generation
- Verification and audit logging
- Network isolation / sovereign deployment
- Web-based workbench interface

## Development Environment

- Windows 11
- Python
- FastAPI
- Ollama
